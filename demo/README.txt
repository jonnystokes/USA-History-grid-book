This folder is THROWAWAY demo data used only to test the grid HTML viewer program. It is NOT
part of the real 35-chapter history book and should never be merged into it. It contains three
fun, made-for-testing "lenses" -- Spooky America (monsters, witches, and ghosts), Sweet Tooth
(candy and dessert), and Thinking Machines (counting and computers) -- each looking at the same
ten eras from Before 1500 down to today. Every cell uses real, well-known facts written in short
finished prose (grid-marker format v3, mode="prose"), and the set is arranged to exercise every
viewer feature: empty and thin cells, full cells, stories with and without real films, famous and
ordinary people, and cells where the narration zooms from an era in to a single story and back out.
Use DEMO-BOOK-OUTLINE.md (the three chapters combined, with an orientation note on top) as the file
to hand the viewer; the three per-chapter .md files are the same content split apart.
